# 🖋️ Pen & Pixel

A full-stack blogging platform built with **Node.js**, **Express.js**, **MongoDB**, and **EJS**. Users can create, read, update, and delete blog posts through a clean, responsive interface, with all content stored persistently in a MongoDB database.

---

## ✨ Features

* 📝 Create new blog posts
* 📖 View individual posts
* ✏️ Edit existing posts
* 🗑️ Delete posts
* 💾 Persistent data storage with MongoDB
* 📅 Automatic post timestamps
* 📱 Responsive user interface
* 🎨 Custom styling with CSS
* ⚡ Dynamic server-side rendering using EJS

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AbdoElkafrawy/pen-and-pixel.git
```

### 2. Navigate to the project

```bash
cd pen-and-pixel
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure MongoDB

Create a MongoDB database (either locally or with MongoDB Atlas), then update the connection string in your project.

### 5. Run the application

```bash
npm start
```

or

```bash
node index.js
```

If you're using Nodemon:

```bash
nodemon index.js
```

### 6. Open in your browser

```
http://localhost:3000
```
