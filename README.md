# Blog Project

A responsive blog application built with Node.js, Express.js and EJS.

## Features

- Create blog posts
- Edit existing posts
- Delete posts
- Responsive layout
- Dynamic rendering using EJS

## Tech Stack

- Node.js
- Express.js
- EJS
- HTML5
- CSS3

## Installation

Clone the repository

```bash
git clone <your repository url>
```

Install dependencies

```bash
npm install
```

Run the application

```bash
nodemon index.js
```

Visit

```
http://localhost:3000
```
